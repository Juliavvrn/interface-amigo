# Индексируемый HTML для juliaveresova.ru

## Что изменим
- Поместим содержательное описание портфолио прямо в `#root`, а не только в `<noscript>`, чтобы нейросети и поисковые роботы, не исполняющие JavaScript, видели текст страницы.
- При запуске React статический контент будет корректно заменяться интерактивным сайтом без изменения его дизайна и функций.
- Сохраним SEO-метаданные, canonical и Open Graph на домене `juliaveresova.ru`.

## Проверка
- Соберём production-версию и проверим итоговый `dist/index.html` без JavaScript.
- Проверим обычную страницу с JavaScript в браузере, чтобы статический fallback не мешал интерфейсу.
- После деплоя HTML-ответ сайта будет содержать H1, описание, компетенции, кейсы, форматы работы и контакты непосредственно в теле документа.

## Технические детали
- Причина: многие AI-парсеры игнорируют содержимое `<noscript>` и видят только пустой `<div id="root"></div>`.
- Решение не требует SSR или изменения статического деплоя Timeweb.
